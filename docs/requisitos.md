# Requisitos do sistema

## Funcionais

RF01 — cadastrar dados da instalação.
RF02 — selecionar sistema monofásico, bifásico ou trifásico.
RF03 — cadastrar cômodos.
RF04 — calcular área e perímetro.
RF05 — estimar carga de iluminação.
RF06 — cadastrar TUG.
RF07 — cadastrar equipamentos específicos.
RF08 — dividir cargas em circuitos.
RF09 — calcular corrente.
RF10 — selecionar seção preliminar.
RF11 — calcular queda de tensão.
RF12 — selecionar proteção preliminar.
RF13 — mostrar distribuição por fase.
RF14 — exportar/importar JSON.
RF15 — gerar relatório HTML.

## Não funcionais

RNF01 — funcionamento sem banco.
RNF02 — interface responsiva.
RNF03 — linguagem clara.
RNF04 — cálculos separados da interface na próxima versão.
RNF05 — registro das hipóteses.
RNF06 — não apresentar resultado preliminar como projeto definitivo.
RNF07 — tabelas normativas versionadas.
